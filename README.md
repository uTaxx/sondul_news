# 손덜 키워드 뉴스

키워드 기반 뉴스·공시 모니터링 구독 서비스의 **화면**입니다.
수집·분석·발송은 n8n(`sondullab.app.n8n.cloud`)이 하고, 이 저장소는 화면만 담습니다.

## 주소

<https://utaxx.github.io/sondul_news/>

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 고객용 본체. 기사 조회 / 키워드 설정 / 키워드 검색 / 구독 관리 4개 화면 |
| `hub.html` | 텔레그램·메일 알림 링크가 `hub.html`이라, 붙어 온 쿼리를 그대로 들고 `index.html`로 넘겨주는 스텁 |

## 배포

`main`에 푸시하면 GitHub Pages가 저장소 루트를 그대로 올립니다.
빌드 단계가 없습니다 — 의존성 없는 정적 HTML이라 빌드할 것이 없고,
단계를 두면 그 단계가 깨질 때 대시보드까지 같이 멈추기 때문입니다.

## 화면이 부르는 것

n8n 웹훅을 직접 호출합니다.

```
sondul-lookup         내 설정 불러오기
sondul-intake         설정 저장
sondul-articles       수집된 기사 목록
sondul-instant        지금 조회
sondul-adhoc-search   특정 키워드 조사
sondul-feedback       기사 평가(도움됐어요 / 필요없어요)
```

## 이 저장소는 공개입니다

비밀값을 두지 않습니다. 고객 식별과 관리자 인증은 전부 **웹훅(서버)에서** 확인합니다.
화면은 `?c=식별코드&t=접근토큰`을 받아 그대로 웹훅에 넘길 뿐이고,
토큰이 맞는지는 서버가 판단합니다.

## 회사용 시스템과의 관계

사내용 LX Group MI와 **완전히 분리**돼 있습니다.
구글 시트, n8n 워크플로, 웹훅 경로, 텔레그램 봇, 저장소가 모두 별개입니다.
어느 한쪽을 고쳐도 다른 쪽에 영향이 없어야 하며, 이 원칙을 깨는 참조를 추가하지 않습니다.
